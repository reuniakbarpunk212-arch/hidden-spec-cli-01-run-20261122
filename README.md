mend: one patch tool for every AI edit format. It applies unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits to a tree of text files — all or nothing, with three-tier line matching (exact, trailing-whitespace blind, indent blind) and the nearest occurrence to the line number the patch names.
